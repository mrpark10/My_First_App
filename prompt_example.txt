==============================================================
  MoodBoard — Copilot Agent 프롬프트 예시 모음
==============================================================

이미 동작하는 Flutter 앱이 만들어져 있어요.
지금 상태에서 뭐가 되는지 먼저 확인하고, 한 STEP 씩 늘려가세요.

[현재 동작하는 것]
- 5개 이모지 버튼(😊 😐 😴 😢 😡) 을 누르면 +1 투표
- 가로 막대 차트가 실시간으로 바뀜
- 가장 많이 눌린 이모지에 👑 표시
- 익명 한 줄 메시지 입력 → 아래 리스트에 표시
- 총 참여 수 표시

[현재 아직 안 되는 것]
- 새로고침하면 데이터가 사라짐 (메모리에만 저장)
- 이모지가 차트로 슝~ 날아가는 애니메이션
- 메시지가 옆으로 흐르는 전광판 효과
- 여러 학급(반) 코드 관리, 실시간 다중 사용자
- 과거 기록 / 캘린더

[프롬프트 잘 쓰는 팁]
1. 한 번에 한 STEP 만. "전부 다 만들어줘" ❌
2. 어떤 파일을 건드릴지 명시. "lib/widgets/emoji_vote.dart 에서만 작업해줘"
3. 결과 확인 방법까지 적기. "핫 리로드 후 버튼 클릭 시 콘솔에 …"
4. 패키지를 추가했다면 pubspec.yaml 수정과 `flutter pub get` 도 같이 알려달라고 하기


--------------------------------------------------------------
STEP 0. 일단 실행해보기
--------------------------------------------------------------
터미널에서:
  flutter pub get
  flutter run -d chrome

크롬 창이 뜨고, 이모지 버튼을 누르면 아래 차트가 늘어나는지 확인.
메시지 입력 후 "보내기" 누르면 리스트에 쌓이는지 확인.


--------------------------------------------------------------
STEP 1. 새로고침해도 유지되도록 (shared_preferences)
--------------------------------------------------------------

[프롬프트 예시]
"앱을 새로고침하면 투표 수와 메시지가 사라져. shared_preferences 로 저장해줘.

조건:
 - pubspec.yaml 의 dependencies 에 shared_preferences: ^2.2.0 추가 후 `flutter pub get` 안내
 - lib/data/mood_repository.dart 를 수정해서:
   - addVote / addMessage 가 호출되면 즉시 prefs 에 저장
   - load() 함수를 만들어 앱 시작 시 prefs 에서 읽어옴 (votes 는 Map<String,int>, messages 는 List<Message>)
   - JSON 직렬화는 jsonEncode / jsonDecode 사용
 - lib/screens/home_screen.dart 의 initState 에서 repo.load() 를 await 한 뒤 setState

힌트: SharedPreferences 는 비동기라 MoodRepository 의 메서드를 Future 로 바꿔야 할 수 있어.
lib/data 와 lib/screens 만 수정하고 위젯 파일은 건드리지 마."


--------------------------------------------------------------
STEP 2. 이모지가 차트로 슝~ 날아가는 애니메이션
--------------------------------------------------------------

[프롬프트 예시]
"lib/widgets/emoji_vote.dart 에서 이모지 버튼을 눌렀을 때
그 이모지가 화면 아래쪽(차트 방향)으로 0.5초간 날아가는 짧은 애니메이션을 추가해줘.

조건:
 - AnimatedPositioned 또는 TweenAnimationBuilder 중 더 단순한 쪽 사용
 - 동시에 여러 개를 누르면 여러 개가 날아갈 수 있도록 (Stack + List<_FlyingEmoji>)
 - 애니메이션이 끝나면 위젯에서 제거
 - 너무 화려하지 않게. 0.5초, 위에서 아래로 자연스럽게

lib/widgets/emoji_vote.dart 만 수정해줘."


--------------------------------------------------------------
STEP 3. 메시지 전광판 효과
--------------------------------------------------------------

[프롬프트 예시]
"lib/widgets/live_board.dart 의 메시지 영역을
오른쪽 → 왼쪽으로 천천히 흐르는 전광판 스타일로 바꿔줘.

조건:
 - 가로 한 줄에 메시지 한 개씩, 끝에 도달하면 화면 밖으로 빠지고 다음 메시지가 나타남
 - 한 메시지가 화면을 가로지르는 시간은 약 6초
 - 메시지가 없으면 '아직 메시지가 없어요' 그대로 유지
 - 새 패키지 없이 AnimationController + Transform.translate 로 직접 구현

기존 ListView 부분만 갈아끼우고, 차트 부분은 건드리지 마."


--------------------------------------------------------------
STEP 4. 학급 코드 (여러 반 분리)
--------------------------------------------------------------

[프롬프트 예시]
"앱을 처음 켰을 때 '학급 코드' 를 입력받는 화면을 추가해줘.

조건:
 - 새 파일 lib/screens/enter_class_screen.dart
 - 입력한 코드(예: '1-2반') 를 shared_preferences 에 저장
 - 이후 앱 시작 시 코드가 이미 있으면 바로 HomeScreen 으로
 - MoodRepository 의 저장 키를 'votes_<코드>' / 'messages_<코드>' 형태로 분리해서
   다른 반 데이터와 섞이지 않게

main.dart 와 mood_repository.dart, 그리고 새 enter_class_screen.dart 만 다루고
emoji_vote / live_board / status_bar 는 건드리지 마."


--------------------------------------------------------------
STEP 5. 가장 많이 눌린 이모지에 왕관 + 짧은 메시지
--------------------------------------------------------------

[프롬프트 예시]
"StatusBar 의 👑 옆에 한 줄 짧은 코멘트를 보여줘.
예: '😊 행복한 하루를 보내고 있어요!' 처럼.

조건:
 - 각 이모지별 코멘트는 lib/models/mood.dart 의 Mood 모델에 'comment' 필드 추가
 - kDefaultMoods 도 그에 맞춰 5개 코멘트 채워줘
 - StatusBar 는 topEmoji 에 해당하는 Mood 의 comment 를 옆에 표시

lib/models/mood.dart 와 lib/widgets/status_bar.dart 만 수정해줘."


--------------------------------------------------------------
STEP 6. (도전) Firebase 로 실시간 다중 사용자
--------------------------------------------------------------

[프롬프트 예시]
"shared_preferences 대신 Cloud Firestore 로 데이터를 저장하면
같은 학급 코드를 가진 다른 학생들과 실시간으로 공유돼.

조건:
 - Firebase Console 에서 프로젝트 만드는 절차를 한국어로 안내해줘 (5줄 이내)
 - cloud_firestore 패키지 추가 안내
 - lib/data/mood_repository.dart 의 저장/불러오기를 Firestore 로 교체
 - 컬렉션 구조 예시: classes/{classCode}/votes, classes/{classCode}/messages
 - HomeScreen 에서 StreamBuilder 로 실시간 갱신

설치 과정은 학생이 직접 해야 하므로 코드 변경 전에 체크리스트를 먼저 보여줘."

"방금 STEP X 를 했는데 [어떤 현상] 이 생겨. 코드를 보고 가능한 원인 3가지와
각각의 해결 방법을 짧게 알려줘. 코드는 아직 고치지 마."

▶ 어디까지 했는지 헷갈릴 때

쪼개줘. 단, 새 패키지 추가는 하지 마."

▶ 되돌리고 싶을 때
"방금 한 변경을 되돌려줘. git status 와 git diff 로 무엇을 되돌릴지 먼저 보여주고,
내가 OK 하면 그때 되돌려."
